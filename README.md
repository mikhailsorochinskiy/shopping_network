# Online Electronics Trade Network Platform

Веб-приложение для управления сетью по продаже электроники с API-интерфейсом и админ-панелью.

## 🚀 Функциональность

### Модели данных
- **Сетевая структура** трех уровней: Завод → Розничная сеть → Индивидуальный предприниматель
- **Динамическое определение уровня** иерархии на основе цепочки поставщиков
- **Управление продуктами** с датами выхода на рынок
- **Финансовая отчетность** с отслеживанием задолженностей

### Админ-панель
- 📊 Визуализация сетевой структуры
- 🔗 Кликабельные ссылки на поставщиков
- 🏙️ Фильтрация по городам
- 💰 Mass-action для очистки задолженностей
- 📈 Детальная аналитика по каждому объекту сети

### REST API
- 🔐 JWT-аутентификация для сотрудников
- 📍 Фильтрация по странам
- 📋 CRUD операции для всех сущностей
- 🛡️ Защита от изменения задолженности через API

## 🛠️ Технологический стек

- **Backend:** Python 3.8+, Django 3+, Django REST Framework
- **Database:** PostgreSQL 10+
- **Authentication:** Token-based auth
- **Filtering:** django-filter
- **API Documentation:** Auto-generated DRF docs
